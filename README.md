# 🏅 NetoSport

**NetoSport** es una aplicación web desarrollada con React para presentar y explorar productos relacionados con el deporte y el equipamiento deportivo. Ofrece una interfaz intuitiva para navegar por el catálogo, consultar los detalles de los productos y gestionar un carrito de compras.

---

## 🚀 Tecnologías utilizadas

- ⚛️ **React** – Desarrollo de interfaces mediante componentes reutilizables.
- 🧭 **React Router DOM 6** – Navegación entre páginas y gestión de rutas dinámicas.
- 🎨 **CSS3** – Diseño visual, estilos y adaptación de la interfaz.
- ⚙️ **JavaScript (ES6+)** – Lógica e interactividad de la aplicación.
- 🧱 **HTML5** – Estructura y contenido del sitio web.
- 🗃️ **React Context API** – Gestión y distribución del estado del carrito.
- 💾 **LocalStorage** – Persistencia de los productos del carrito en el navegador.
- 📦 **Node.js y npm** – Gestión de dependencias y ejecución del proyecto.
- 🛠️ **Create React App** – Configuración y ejecución del entorno de desarrollo mediante react-scripts.

---

## 🧭 Descripción general

NetoSport es una aplicación web orientada al ámbito deportivo, diseñada para ofrecer una interfaz visual atractiva y una navegación sencilla.

El proyecto utiliza React para organizar sus componentes y desarrollar una experiencia dinámica, aplicando conceptos fundamentales del desarrollo frontend y diseño web.

El enfoque principal es proporcionar una plataforma moderna y funcional para presentar contenido relacionado con el equipamiento deportivo.

---

## 📄 Secciones del sitio

### 🏠 Inicio
- Presenta la identidad visual de NetoSport.
- Ofrece una introducción a la propuesta del sitio web.

### 🛍️ Productos
- Muestra productos de equipamiento deportivo.
- Presenta información como nombre, categoría, precio e imágenes.
- Permite acceder al detalle individual de cada producto.

### 🛒 Carrito de compras
- Permite agregar productos al carrito.
- Permite modificar cantidades y eliminar productos.
- Calcula el importe total de los productos seleccionados.
- Conserva el contenido del carrito mediante LocalStorage.

### 📄 Páginas adicionales
- Nosotros: sección informativa sobre la marca.
- Contacto: página dedicada a la información de contacto.
- Detalle de producto: vista individual de cada producto.
- Página no encontrada: gestión de rutas que no existen.

### 🧭 Navegación y experiencia de usuario
- Navegación mediante React Router DOM.
- Carga diferida de determinadas páginas.
- Indicador visual durante la carga de las vistas.
- Gestión de errores de renderizado y opción para volver a cargar la página.
